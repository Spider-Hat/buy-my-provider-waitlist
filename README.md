# BuyMyProvider Waitlist

This repo contains the marketing site for the BuyMyProvider waitlist. It is a Vite + React + TypeScript project that uses Tailwind CSS and shadcn/ui for styling and components.

## Getting started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Run the local dev server**
   ```bash
   npm run dev
   ```
3. **Build for production**
   ```bash
   npm run build
   ```
4. **Preview the production build**
   ```bash
   npm run preview
   ```

## Project structure

- `src/` – React components, hooks, and utilities
- `public/` – Static assets such as the branding graphics and favicon
- `index.html` – Document head metadata and root mounting element
- `vite.config.ts` – Vite configuration (aliases, plugins, dev server)

## Deployment

Deploy the contents of the `dist/` directory produced by `npm run build` to your preferred static hosting provider (e.g., Netlify, Vercel, Cloudflare Pages, S3 + CloudFront, etc.).
